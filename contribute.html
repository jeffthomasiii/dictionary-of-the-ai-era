Editorial contribution

Suggest a term

If you keep seeing an AI-related word, phrase, acronym, or bit of slang that is not in EpochLex, it may belong here. The most helpful suggestions include the term, where you encountered it, what it appears to mean, and one or more examples or sources showing that people actually use it.

Corrections

Correct or strengthen an entry

A published entry can still improve. Useful feedback includes clearer definitions, missing aliases, better example sentences, stronger sources, incorrect dates, questionable origin claims, category or status concerns, and places where the wording has not kept up with actual usage.

Pronunciation

Help us say it correctly

If the written pronunciation is wrong, unclear, or a browser's speaker control says a term incorrectly, report it. Acronyms, new slang, names, and newly coined terms are especially likely to need explicit pronunciation handling.

Quality assurance

Test the site

Accessibility and real-device feedback are contributions too. Reports about keyboard navigation, screen readers, contrast, mobile layouts, dark mode, broken links, search behavior, or browser-specific problems can improve the dictionary for everyone.

Repository work

Contribute code, design, research, or documentation

Developers, researchers, writers, designers, accessibility testers, editors, and documentation contributors can work directly with the project on GitHub. The repository contains the full contribution workflow, editorial standards, architecture, provenance rules, design guidance, project history, roadmap, and AI-transparency documentation.

AI-assisted work

AI-assisted contributions are welcome

AI can be used to help research, draft, code, edit, or organize a contribution. AI output is not evidence by itself, and contributors remain responsible for checking factual claims, verifying sources, reviewing generated work, and ensuring they have the right to submit it.

Publication

Human review remains part of the process

Suggestions, Discussions, issues, and pull requests are inputs to the Living Dictionary, not automatic publication. EpochLex remains human reviewed so that definitions, provenance, sources, design changes, and software behavior can be evaluated before they become part of the public reference.
