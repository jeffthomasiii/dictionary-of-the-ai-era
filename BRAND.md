# EpochLex Brand

## Name

**EpochLex**

## Pronunciation

**/EP-uk-leks/**

Say **epoch** followed by **lex**.

## Descriptor

**Dictionary of the AI Era**

The descriptor explains what EpochLex is without competing with the primary brand name.

Preferred presentation:

> **EpochLex**  
> *Dictionary of the AI Era*

## Meaning

EpochLex combines **epoch** with **lexicon**.

The name reflects the project's purpose: documenting the vocabulary emerging during an AI-shaped era. That vocabulary includes technical terminology, cultural slang, workplace language, governance concepts, research language, and other words whose meaning or importance is being shaped by artificial intelligence.

The name is intentionally broader than a conventional AI glossary. EpochLex documents the language of an era, not only the components of AI systems.

## Naming usage

Use **EpochLex** as the primary name in:

- page titles;
- site header and masthead;
- navigation identity;
- repository documentation;
- social and promotional references;
- annual-edition naming;
- future domain and repository naming.

Use **Dictionary of the AI Era** as:

- subtitle;
- tagline;
- project descriptor;
- explanatory metadata where additional context is useful.

## Pronunciation placement

The pronunciation does not need to appear beside the EpochLex wordmark on every page. Keep the primary masthead clean.

Make **/EP-uk-leks/** explicit in:

- the About page;
- the repository README;
- brand documentation;
- onboarding or first-use contexts where useful.

## Brand history

The project began under the working name **Dictionary of the AI Era**.

As the first short-form identity developed, it became **AILex**, combining AI with lexicon. A later public-identity review found meaningful naming collisions with other active products and organizations. Before a custom domain or repository rename was committed, the project adopted **EpochLex** as the durable public brand.

This was a brand change, not a new project. The dictionary, editorial methodology, open-source intent, provenance system, and human-directed AI/vibe-coding experiment continue directly from the same work.

Historical documentation may refer to **AILex** when describing that earlier stage of the project. Current product references should use **EpochLex**.

## Repository strategy

The current repository name, `dictionary-of-the-ai-era`, predates both short-form brand names. It remains intentionally unchanged during the EpochLex identity migration so existing GitHub Pages URLs and external references are not casually broken.

A future repository transition should evaluate:

1. whether to rename the repository to an EpochLex-based slug;
2. GitHub redirect behavior for the old repository URL;
3. GitHub Pages behavior after a repository rename;
4. documentation, contribution links, badges, and external references;
5. whether retaining the descriptive repository slug has practical value.

## Domain strategy

EpochLex should eventually use a short, memorable public URL if a suitable domain or subdomain is available and appropriate.

Domain selection and repository renaming are separate from this brand migration. When that transition occurs, canonical URLs, sitemap URLs, social metadata, redirects, GitHub Pages configuration, and documentation should be updated together.

Until then, the product can be fully branded as EpochLex while continuing to use the existing GitHub Pages address.
