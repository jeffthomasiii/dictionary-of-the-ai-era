# AILex Brand

## Name

**AILex**

## Pronunciation

**/A-I-lex/**

Say the letters **A** and **I**, followed by **lex**.

## Descriptor

**Dictionary of the AI Era**

The descriptor explains what AILex is without competing with the primary brand name.

Preferred presentation:

> **AILex**  
> *Dictionary of the AI Era*

## Meaning

AILex combines **AI** with **lexicon**. The name is intended to be short, memorable, and broad enough to cover technical terminology, cultural slang, workplace language, governance concepts, and future vocabulary that develops around artificial intelligence.

## Naming usage

Use **AILex** as the primary name in:

- page titles
- site header and masthead
- navigation identity
- repository documentation
- future social and promotional references
- future domain and repository naming

Use **Dictionary of the AI Era** as:

- subtitle
- tagline
- project descriptor
- explanatory metadata where additional context is useful

Avoid using **Dictionary of the AI Era** as the primary product name once the AILex branding transition is complete.

## Pronunciation placement

The pronunciation does not need to appear beside the AILex wordmark on every page. Keep the primary masthead clean.

Make **/A-I-lex/** explicit in:

- the About page
- the repository README
- brand documentation
- future onboarding or first-use contexts where useful

## Repository strategy

The current repository name, `dictionary-of-the-ai-era`, predates the AILex brand decision. Do not rename it casually while active links, GitHub Pages configuration, or external references may depend on it.

A future repository transition should evaluate:

1. renaming the repository to an AILex-based slug, preferably `ailex` if available and appropriate;
2. GitHub redirect behavior for the old repository URL;
3. GitHub Pages configuration after a repository rename;
4. references in documentation, contribution links, badges, and external sites;
5. whether preserving `dictionary-of-the-ai-era` as a descriptive repository name has practical benefits even after AILex becomes the public brand.

## Domain strategy

AILex should eventually use a short, memorable public URL if a suitable domain or subdomain is available. Domain selection should happen separately from the branding commit so availability, trademark risk, redirects, and long-term ownership can be evaluated deliberately.

Until that decision is made, the product can be fully branded as AILex without changing the underlying repository or GitHub Pages URL.
