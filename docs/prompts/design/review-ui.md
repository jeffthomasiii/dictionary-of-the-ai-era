# Prompt Template: Review an EpochLex Interface

Use this template to evaluate an existing or proposed interface without automatically redesigning it.

## Prompt

Review the following EpochLex interface or design change.

### Interface to review

[Provide screenshots, URL, branch, files, mockup, or description.]

### Intended purpose

[Explain what the interface is supposed to help the reader do.]

### Relevant context

[Provide the issue, requirement, `DESIGN.md` sections, brand guidance, or other applicable project material.]

### Requested output

Provide a prioritized design review with concrete findings and recommendations.

### EpochLex instructions

Evaluate the interface against established EpochLex documentation and the task's intended purpose, not against an invented design system.

Consider, where applicable:

- information hierarchy and readability;
- clarity of search, browse, filter, or reference interactions;
- consistency with existing EpochLex patterns;
- desktop, tablet, and mobile behavior;
- light and dark themes;
- keyboard and visible-focus behavior;
- whether meaning depends on color alone;
- whether the design preserves the underlying information architecture and data semantics.

Separate actual conflicts or usability problems from subjective preferences. Do not recommend a wholesale redesign when a focused correction would address the problem.

For each finding, explain what you observed, why it matters, and what change you recommend. Clearly identify suggestions that would introduce a new design decision rather than apply an existing EpochLex standard.

If screenshots or supplied context do not allow you to validate a behavior, identify the limitation rather than assuming how the interface works.
