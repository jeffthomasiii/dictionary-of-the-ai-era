About the project

A dictionary, not just a glossary.

This project catalogs the vocabulary developing around artificial intelligence: technical concepts, new ways of working, emerging slang, and language related to AI risk and governance. Definitions are written for clarity first and are intended to evolve as the language does.

Yes, this project is vibe coded. AI is not only something this dictionary documents; it is part of how the dictionary itself is built. The project is human-directed, AI-assisted, and human-reviewed, with human editorial judgment governing what ultimately gets published.
